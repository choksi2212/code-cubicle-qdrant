# Deploy FieldEdge sync API to Render

## One-time setup

1. **Sign in to Render** at https://dashboard.render.com (GitHub login works).

2. **Create the service from Blueprint:**
   - Click **New** → **Blueprint**
   - Connect your GitHub account if not already
   - Point it at the `field-edge` repo
   - Render will detect `apps/sync-api/render.yaml` and create the `field-edge-sync-api` web service

3. **Set the secrets** before first deploy (Render dashboard → service → Environment):
   - `QDRANT_URL` = `https://790d645c-576d-484c-bd4b-be5147fab877.ca-central-1-0.aws.cloud.qdrant.io`
   - `QDRANT_API_KEY` = the API key from `.env` (paste from `C:\Users\niklaus\...\.env`)
   - `JWT_SECRET` = auto-generated by Render (you can leave the `generateValue: true` line in render.yaml)

4. **First deploy** will take ~3-5 min (Docker build + pip install). Once live, you'll get a URL like:
   ```
   https://field-edge-sync-api.onrender.com
   ```

5. **Verify the deploy** (replace `<your-url>`):
   ```bash
   curl https://<your-url>/readyz
   # → {"status":"ready","qdrant_collection":"field_edge_central","qdrant_points":17, ...}
   curl https://<your-url>/sync/heartbeat
   ```

## Update the mobile app to point at the live URL

After the first deploy succeeds, the URL is stable. Update `apps/mobile/src/config.ts`:

```ts
const ENV_URL = ...process.env.SYNC_API_URL... || 'https://field-edge-sync-api.onrender.com';
```

Then rebuild the JS bundle and APK:

```bash
cd apps/mobile
export SYNC_API_URL=https://field-edge-sync-api.onrender.com
npx react-native bundle --platform android --dev false --entry-file index.js \
  --bundle-output android/app/src/main/assets/index.android.bundle \
  --assets-dest android/app/src/main/res
cd android && ./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Notes

- **Free plan** spins down after 15 min of inactivity. First request after sleep takes ~30s (cold start). Acceptable for the demo; the heartbeats keep it warm if you wire that up later.
- **Region:** `oregon` (closest to Qdrant's `ca-central-1` isn't an option; oregon→ca-central-1 has low latency).
- **Health check:** `/sync/heartbeat` every 30s — Render restarts the service on 3 consecutive failures.
- **Logs:** Available in Render dashboard → Logs tab.
